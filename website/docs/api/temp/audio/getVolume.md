# care.temp.audio.getVolume

<span class="api-kind">Function</span>

Returns the master audio volume.

## Syntax

```lua
volume = care.temp.audio.getVolume()
```

## Arguments

None.

## Returns

| Name | Type | Description |
| --- | --- | --- |
| `volume` | number | Current master volume between 0 and 1. |

## Example

```lua
local volume = care.temp.audio.getVolume()
```
