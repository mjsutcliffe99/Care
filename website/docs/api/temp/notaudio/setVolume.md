# care.temp.notaudio.setVolume

Sets the master notaudio volume.

## Syntax

```lua
care.temp.notaudio.setVolume(volume)
```

## Arguments

| Name | Type | Description |
| --- | --- | --- |
| `volume` | number | Master volume from 0 to 1. |

## Returns

Nothing.

## Example

```lua
care.temp.notaudio.setVolume(0.5)
```
