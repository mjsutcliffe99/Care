Sets the volume of the source.

## Syntax

```lua
source:setVolume(volume)
```

## Arguments

| Name | Type | Description |
| --- | --- | --- |
| `volume` | number | Source volume from 0 to 1. |

## Returns

Nothing.

## Example

```lua
music:setVolume(0.25)
```
